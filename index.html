Chapter 1

為什麼你需要 AI 策略模板？

短線交易者每天面對的資訊洪流，早已超過人腦能有效處理的極限。

你每天需要追蹤多少資訊？

  • 技術面：均線、KD、RSI、MACD、布林通道…… 每支股票都要看
  • 籌碼面：外資、投信、自營商買賣超，三大法人動態
  • 消息面：財報、法說會、產業新聞、國際市場動態
  • 心理面：恐慌貪婪指數、市場情緒、散戶籌碼分布

傳統手動整理 vs. Claude AI 輔助

比較項目 傳統手動整理 Claude AI 輔助
每日整理時間 2~4 小時 10~20 分鐘
同時追蹤標的數 3~5 支（精力有限） 10~20 支（模板化）
技術指標覆蓋 2~3 個習慣指標 全面標準化分析
情緒干擾 高（恐懼/貪婪影響判斷） 低（AI 客觀條列分析）
一致性 因狀態波動大 每次格式統一
學習曲線 需多年積累 30 分鐘入門
⚠️ 重要定位說明：Claude 是你的「研究助理」，不是自動下單機器人。AI 可以幫你整理資訊、提供參考框架，但所有交易決策仍在你手上。任何 AI 分析都不能取代你對市場的判斷與風險承擔。

Chapter 3

第一次下命令 ——
建立你的基礎短線分析 Prompt

Prompt（提示詞）Prompt 就是你給 AI 的工作指令，就像告訴助理「你的職責是什麼、請怎麼幫我做事」 是你和 AI 溝通的橋梁。一個好的 Prompt 等於僱了一位懂你需求的分析師。

什麼是 Prompt？

Prompt 就是你給 AI 的工作指令。就像你告訴助理「你是短線分析師，請按照這個格式幫我分析股票」——越清楚的指令，就能得到越精準的回覆。

萬用短線分析 Prompt 模板

直接複製以下提示詞，貼入 Claude 對話框即可使用：

📋 基礎短線分析 Prompt 模板
你是一位經驗豐富的短線交易策略分析師。請根據我接下來提供的股票代號與期間，進行短線分析。 分析需包含： 1. 技術面（5日、10日、20日均線、KD、RSI、MACD 現況） 2. 籌碼面（外資、投信、自營商買賣超） 3. 近期重大新聞與事件影響 4. 關鍵支撐與壓力區間 5. 短線操作建議與風控提醒 請以條列式呈現，語氣客觀，最後加上： 「以上為 AI 輔助分析，僅供參考，實際交易請自行判斷。」

示範對話流程

①

貼上 Prompt

開啟 Claude，將上方完整 Prompt 複製後貼入對話框，按 Enter 送出。

②

提供股票代號

Claude 回覆確認後，你輸入：
「請分析 2330 台積電，時間框架為最近 5 個交易日。」

③

取得完整分析

Claude 將依照格式輸出技術面、籌碼面、新聞面完整條列分析，以及建議與風控提醒。

📡 重要提醒：Claude 預設不會主動連網取得即時數據，分析結果基於其訓練資料。要取得最新台股數據，需要：①開啟聯網搜尋功能，或 ②整合 FinMind API（第四章說明），或 ③手動上傳資料（第五章說明）。

4.1 前往 FinMind 官網

FinMind 提供兩個重要入口：

  • 官方文件（API 說明）：https://finmind.github.io/ — 查閱所有可用的數據集與參數說明
  • 會員中心（登入/註冊）：https://finmindtrade.com/ — 在此建立帳號並取得 API Token

4.2 如何註冊 FinMind 帳號

1

前往官網並點擊「加入會員」

開啟 https://finmindtrade.com/，點選右上角「加入會員」或「Sign Up」按鈕。

2

填入 Email 與密碼

輸入你常用的 Email 地址與自訂密碼，點選「立即註冊」。系統會發送驗證信至你的信箱。

3

驗證 Email 並登入

開啟驗證信，點擊確認連結後即可回到網站登入。登入後進入你的帳戶主頁。

4.3 如何取得 API Token（金鑰）

1

登入後進入帳戶設定

在 finmindtrade.com 登入後，點選上方導覽「個人資料」或直接找「API Token」區塊。

2

複製你的 API Token

Token 是一串長字元（約 32~64 字元），例如：eyJhbGciOiJIUzI1NiI...。點選複製按鈕儲存。

3

妥善保存 Token

將 Token 貼入記事本或密碼管理工具。不要公開分享這個 Token，它等同於你的 API 帳號密碼。

4.4 測試你的 API

將以下 URL 複製後，把 YOUR_TOKEN 換成你的實際 Token，貼入瀏覽器網址列按 Enter，即可看到 JSON 格式的股價資料。

範例：查詢台積電（2330）近期股價 https://api.finmindtrade.com/api/v4/data?dataset=TaiwanStockPrice&data_id=2330&start_date=2025-01-01&token=YOUR_TOKEN
範例：查詢三大法人買賣超 https://api.finmindtrade.com/api/v4/data?dataset=TaiwanStockInstitutionalInvestors&data_id=2330&start_date=2025-01-01&token=YOUR_TOKEN

✅ 成功的回應格式長這樣：

{"msg": "success", "status": 200, "data": [{"date": "2025-01-02", "stock_id": "2330", "open": 1020, "max": 1035, "min": 1015, "close": 1030, "volume": 12345}]}

4.5 在 Claude 中建立 FinMind Skill（技能）

Skill（技能）Skill 是 Claude 的專屬能力設定，透過 Custom Instructions 或 Project，讓 Claude 每次對話都「記得」如何使用 FinMind 資料 是讓 Claude 長期記住「如何使用你的 FinMind 帳號查詢台股資料」的設定。以下提供三種方式，由簡到難：

方法 A 推薦

建立 Claude 專案（Project）作為 FinMind Skill

透過 Claude 的「專案」功能，建立一個永久記憶 FinMind 設定的分析環境。適合 Claude Pro 用戶。

①

開啟 Claude 桌面版，點選左側「+ 新增專案」

或在 claude.ai 網頁版點擊左側「Projects」→「New Project」。

②

命名專案

例如：「台股短線分析 × FinMind」，清楚說明這個專案的用途。

③

在「專案指令」貼入下方 FinMind Skill Prompt

將自己的 API Token 填入後，貼入「Project Instructions」欄位，儲存即可。

🔧 FinMind Skill — Project Instructions 模板
你是一位整合 FinMind 台股資料的短線分析師 AI。 【FinMind API 資訊】 - 文件來源：https://finmind.github.io/ - API 端點：https://api.finmindtrade.com/api/v4/data - 我的 API Token：[在此填入你的 FinMind Token] 【可使用的主要數據集】 - TaiwanStockPrice：個股日K股價（開高低收量） - TaiwanStockInstitutionalInvestors：三大法人買賣超 - TaiwanStockMarginPurchaseShortsale：融資融券 - TaiwanStockFinancialStatements：財務報表 - TaiwanStockMonthRevenue：月營收 【你的工作方式】 當我提出股票分析需求時，你應該： 1. 列出需要查詢的 FinMind 數據集及對應 API URL 2. 等我提供查詢結果（JSON 資料）後再進行分析 3. 依照標準格式輸出技術面、籌碼面、操作建議 若我直接貼入 JSON 資料，請立即進行短線分析，格式如下： - 技術面分析 - 籌碼面分析 - 關鍵支撐與壓力 - 短線操作建議與風控提醒 - 以上為 AI 輔助分析，僅供參考，實際交易請自行判斷。
方法 B 免費版可用

使用 Custom Instructions（自訂指令）

適合免費版用戶。在 Claude 帳戶設定中加入 FinMind 說明，讓每次對話都自動套用。

①

進入 Claude 設定

點選右上角頭像 → 「Settings」→「Custom Instructions」（或「個人化」）。

②

在「How would you like Claude to respond?」中填入

貼入包含你的 FinMind Token 和分析格式偏好的自訂指令，儲存後所有新對話都會套用。

方法 C 進階

請 Claude 撰寫 Python 腳本自動抓取

讓 Claude 幫你寫一個 Python 腳本，執行後自動從 FinMind 抓取數據並輸出分析報告。適合有基本電腦操作能力、願意安裝 Python 的用戶。

🐍 請 Claude 產生 FinMind Python 查詢腳本
請幫我撰寫一個 Python 腳本，使用 FinMind API 查詢以下資料，並輸出方便分析的格式： 1. 台積電（2330）最近 10 個交易日的日K資料（開高低收量） 2. 台積電最近 10 個交易日的三大法人買賣超 FinMind API Token：[你的 Token] API 文件：https://finmind.github.io/ 請包含完整 import、錯誤處理，並在輸出時清楚標示每筆資料的欄位名稱。 腳本完成後告訴我如何執行（需要哪些套件）。
🔑 資安提醒：你的 API Token 是私密金鑰，請不要分享給他人或貼在公開的網路平台。FinMind 免費方案每日限 600 次請求，足夠個人日常使用。如需更高頻率，可升級至付費方案。
Chapter 5

如何抓取即時資料 ——
聯網搜尋與上傳文件

除了 FinMind API，還有其他方式讓 Claude 取得最新台股數據。

方式一：啟用聯網搜尋功能

如何開啟聯網（Web Search）

在 Claude 對話輸入框下方，找到「🌐 搜尋」或「Search the web」按鈕（圖示為地球或放大鏡），點擊啟用後，Claude 即可搜尋即時網路資訊。

🌐 聯網搜尋指令範例
請搜尋今日台股 2330 台積電的即時走勢與三大法人買賣超數據，並根據前述分析模板進行更新分析。

方式二：上傳 CSV / Excel 資料（免費版替代方案）

若沒有聯網功能，可從券商軟體或財經網站下載數據，直接拖曳到 Claude 對話框上傳。

標準化資料上傳格式（CSV 範例）

請將你的數據整理成以下格式後上傳：

date open high low close volume
2025-01-02 1020 1038 1015 1030 25430
2025-01-03 1032 1055 1028 1048 31200
📁 CSV 上傳後的分析指令
我上傳了過去 10 個交易日的 2330 台積電日K資料，請依照前述模板進行短線分析。 重點關注： 1. 近期均線型態（是否多頭排列？） 2. 量能變化趨勢 3. 目前所處的支撐與壓力位置

Chapter 7

將模板儲存為標準操作流程（SOP）

讓每天的分析流程像「開機就能用」一樣順暢。

1

複製你最終滿意的完整 Prompt

Chapter 8

完成說明文檔與注意事項

在開始用 AI 輔助交易之前，請確認你完全理解以下重要原則。

⚖️

AI 輔助的正確定位

Claude 是效率工具，不是獲利保證機器。它能幫你整理資訊、減少遺漏、加快分析速度，但市場永遠有不可預測的部分。所有的最終決策、資金管理、停損執行，仍然完全由你負責。

📡 資料時效性提醒

聯網搜尋和 FinMind API 的資料可能有延遲（通常為 15 分鐘至數小時）。關鍵即時數據請以券商交易系統的報價為準，AI 分析僅作參考框架。

🛡 風險控管鐵律

無論 AI 分析結果多麼看好，請務必：①設定明確停損點位、②嚴格執行倉位管理、③不超額使用槓桿。這些是獨立於任何分析工具之外的基本紀律。

🔒 資料隱私保護

可關閉 Claude 聯網功能，僅上傳去識別化的技術數據（去除帳號、持倉、個人資訊）。避免在對話中提供個人帳戶資料或具體持倉明細。

🌱 持續優化模板

市場邏輯比複雜指標更重要。不要堆疊過多指標，而是深入理解每個指標代表的市場含義。每月檢視一次你的 Prompt，根據近期市場特性調整。

FAQ

常見問題 FAQ

Q：Claude 能直接幫我下單嗎？
▾
不行，也絕對不要嘗試這樣做。Claude 是分析輔助工具，不具備連接券商 API 或執行交易的功能。所有買賣決策必須由你親自在券商系統中執行。
Q：免費版的 Claude 足夠使用嗎？
▾
輕度使用（每日 3~5 次分析）免費版足夠。重度使用者建議升級至 Pro 版（約 USD $20/月），享有更長的上下文視窗（可處理更大量的歷史數據）、更高訊息額度以及優先存取權。FinMind 的免費方案每日 600 次請求，也足夠個人日常使用。
Q：我擔心對話資料的隱私問題。
▾
建議：①關閉 Claude 的聯網功能，只上傳去識別化的技術數據；②不要在對話中輸入你的帳號密碼、持倉明細或個人金融資訊；③可在 Claude 設定中關閉「使用對話資料訓練模型」的選項。FinMind API Token 也請妥善保管，不要公開分享。
Q：Claude 的分析結果不準確怎麼辦？
▾
請先確認：①是否提供了最新的實際數據（透過 FinMind API 或 CSV 上傳）；②Prompt 是否足夠具體；③是否有追問調整分析框架。AI 的準確度高度依賴你給的資料品質。建議交叉比對券商系統數據和其他財經平台資訊，不要將 AI 分析視為唯一依據。
Q：FinMind API 的免費額度夠用嗎？
▾
免費方案每日 600 次請求，對個人每日分析 10~20 支股票（每支查詢 2~3 個數據集）完全足夠。若你需要批次抓取大量歷史資料或自動化腳本，可考慮 FinMind 的付費方案，詳情請參閱 finmind.github.io 的方案說明。
Q：如何讓 Claude 記住我的個人分析偏好？
▾
有兩種方式：①使用 Claude 的「Projects（專案）」功能，在專案指令中設定你的所有偏好（推薦，Pro 版功能）；②使用「Custom Instructions（自訂指令）」，在帳戶設定中填入你的偏好，適用於所有對話。兩種方式在本教學第四章和第六章都有詳細說明。
Q：我完全不懂程式，可以使用 FinMind API 嗎？
▾
可以！最簡單的方式是把 API URL 直接貼入瀏覽器網址列（第四章 4.4 節的範例），瀏覽器會回傳 JSON 格式的數據，你再把這些數據複製貼入 Claude 對話框即可。不需要任何程式知識。如果你想更自動化，可以請 Claude 幫你生成 Python 腳本（方法 C），Claude 會提供完整的執行說明。
